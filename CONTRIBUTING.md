# Contributing

Thanks for helping improve Portfolio Builder.

Before opening a change:

1. Keep the skill focused on data portfolio projects rather than portfolio website design or general career advice.
2. Preserve the evidence gate: no detailed plan before usable data evidence has been inspected.
3. Do not add instructions that encourage invented findings, targets, internal company facts, causal claims, or credentials.
4. Add or update test cases for every behavior change.
5. Run the full Critical and High test set before proposing a release.

Use the repository Issues tab for bugs and focused enhancement proposals. Do not include private datasets, credentials, or personal information in an issue.
