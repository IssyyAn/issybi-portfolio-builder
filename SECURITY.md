# Security

Portfolio Builder is a skills-only plugin. It has no developer-operated server, account connection, or authentication flow.

Please do not submit passwords, access tokens, connection strings containing credentials, unrestricted production access, or private datasets in public issues. For SQL projects, use a database file, schema export, ERD, redacted sample rows, or query extracts whenever possible.

Report instruction-integrity or sensitive-data-handling concerns through the repository Issues tab without including the sensitive material itself.
