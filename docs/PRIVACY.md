# Privacy Policy

Effective date: 24 September 2026

Portfolio Builder is a skills-only plugin published by Issy BI. It does not operate a separate developer-owned server, create user accounts, use independent authentication, or transmit data to an Issy BI service.

## Information the skill uses

The workflow can use information that a user chooses to provide in a conversation, including project ideas, datasets, schemas, screenshots, data dictionaries, queries, and existing project materials. That information is processed within the ChatGPT or Codex product where the skill is used, subject to the applicable OpenAI terms and privacy controls.

## Information Issy BI collects

Issy BI does not independently collect, receive, sell, or retain the contents of user conversations or uploaded files through this skills-only plugin.

If a user voluntarily opens a public repository issue, the information included in that issue is handled by the repository host and is visible according to that issue’s visibility. Users should not post private data, credentials, or personal information in public issues.

## Data safety

The skill instructs users not to share passwords, secrets, unrestricted production access, or connection strings containing credentials. It recommends portable and redacted evidence such as database files, schema exports, ERDs, representative sample rows, and query extracts.

Users are responsible for ensuring they have the right to upload and analyse any data they provide and for complying with applicable privacy, confidentiality, employment, and data-protection obligations.

## Changes

Material changes to this policy will be recorded in the repository history and release notes.

## Contact

Use the repository Issues tab for privacy questions without including sensitive information.
