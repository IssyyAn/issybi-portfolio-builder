# Support

Use the repository Issues tab for:

- reproducible behavior that conflicts with the skill instructions;
- installation or package problems;
- test-case failures;
- unclear or contradictory guidance; and
- focused enhancement proposals.

When reporting a problem, include the plugin version, the exact prompt, the expected behavior, and a redacted excerpt of the result. Do not include private datasets, credentials, personal data, or confidential company information.

Portfolio Builder is a free project. Support is provided on a reasonable-effort basis, with no guaranteed response time.
